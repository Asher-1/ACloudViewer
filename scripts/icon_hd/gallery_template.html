Methodology · root causes & fixes

  
Root cause: the old pipeline (contour smoothing / gradient fits / potrace Beziers / patch blend layers) "invented geometry" for 16px pixel-art icons, melting crisp pixel structure into blobs; semi-transparent patches over vector paths can never composite to the source math; loose acceptance gates (IoU 0.78) shipped visible errors.

  
Fix: v8 lossless pixel-exact vector transcription — every source pixel (including all faint-alpha detail) → exact rect, 2D run-length merging, crispEdges keeps any integer zoom crisp. The vector payload is a bit-level transcription of the source RGBA.

  
v10 commercial redesign: per-icon ImageGen 1024px commercial repaint (unified art direction: pure white background, 95% occupancy, original colour semantics) → boundary-connected flood-fill keying + boundary-band matting → footprint/centre alignment to the original bbox → two-layer delivery: pure vector (potrace Beziers + linear gradients, 4x gate vs design vmean≤10/vfrac≤10%) else embedded ≤256px HD transparent raster. Semantic-drift safety net: ink IoU≥0.45, white-bg Δfrac≤70%, topology 0.5–2.0. The 48 initial gate failures were reviewed sheet-by-sheet: 40 semantically equivalent manual QA passes, 6 regenerated (ft house, SF/HSV letters, pp stair line art, forest scattered trees), 2 solid fixtures vectorised programmatically. v10.1 review: 5 switched to hand-authored exact vectors (authored/: oblique cubes ×2, ft house line art, gun arc+tree, rpc client↔server semantic replacement — the original arch was meaningless); mapIcon/cork regenerated. Real-ESRGAN anime super-resolution rejected by visual review (grid melting / magenta fringes).

  
Acceptance: v8 SVG vs original PNG within the same Qt render pipeline ≤2/255 per pixel (only 8-bit rounding noise on AA pixels), 1x four backgrounds + 2/3/4x all pass. Diff view is 1x white-bg |SVG−orig| heat with adjustable gain; tri-view shows orig / v8 / v10 side by side. Canvas-fit pass: icons whose ink occupancy <90% are uniformly scaled to 96% (2% optical margin per side); fidelity gates and heat maps compare modulo this declared similarity transform, so detail preservation is still verified exactly.
