# Original QCustomPlot illustration assets: licensing and provenance

These 29 PNGs are newly authored functionality illustrations. Their numeric series, placements, palettes, axes and compositions are generated by `main.cpp`; no official QCustomPlot documentation PNG or layout is used. Every image is titled “Original example” and is not represented as recovery of an upstream release asset.

Preserve the upstream QCustomPlot attribution and license notices. Official QCustomPlot 1.3.1 was used only to compare API image-documentation version and prove no upstream PNG was copied. The generation inputs are hand-authored code and deterministic numeric examples; the PNG compressor is lossless and pixel identity is recorded in `asset-manifest.json`.
