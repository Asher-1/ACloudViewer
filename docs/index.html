About ACloudViewer

ACloudViewer is an open-source 3D point cloud and triangular mesh processing software library. It supports rapid development of software for processing 3D data, highly based on CloudCompare, Open3D, ParaView and COLMAP, and integrates the PCL library.

Originally designed to compare two 3D point clouds (such as those obtained by laser scanning) or the difference between point clouds and triangular meshes. It relies on an octree structure highly optimized for this specific use case, capable of handling massive point cloud data (typically over 10 million points, up to 120 million points with 2GB memory).

Depth Anything V3 (qDA3)

Turn a single photo into a depth map and 3D point cloud. Multi-view depth, camera pose, COLMAP export, and automatic reconstruction integration — all from quantized GGUF weights (~142 MB Base).

  • Single-image depth + optional 3D unprojection in the DB tree
  • Plugs into COLMAP sparse/dense reconstruction pipelines

Face Detection & Recognition (qFaceDetect)

Run SCRFD/YuNet and ArcFace/SFace GGUF packs for face detection, identity registry matching, verification, and live multi-face recognition in one plugin.

  • SQLite identity registry with vectorized cosine-distance matching
  • Camera/video preview and DB-tree annotated image export

LightGlue Feature Matching (qLightGlue)

Match corresponding features between two images in under a second. OpenCV RootSIFT + GGUF LightGlue matcher on GPU — hundreds of mutual matches with live green-line visualization.

  • SIFT LightGlue path: native C++, no ONNX or Python at runtime
  • Export matches as JSON; results added to the DB tree automatically

FreeSplatter 3D Gaussian Splats (qFreeSplatter)

Reconstruct a 3D Gaussian scene from as few as two uncalibrated photos, or collect guided Face Capture views. Optional camera pose estimation, SIBR-compatible PLY export, and one-click qSIBR preview.

  • Sparse-view 3DGS — no COLMAP preprocessing required
  • Full export with spherical harmonics, scale, and normals

YOLO Detection, Segmentation & Depth (qYOLO)

Ultralytics YOLOv8 / YOLO26 GGUF — COCO-80 detection, instance segmentation, metric depth, pose, OBB and classification, plus open-vocabulary World / YOLOE prompts in 100+ languages.

  • 63 published GGUF models across 9 task families
  • Live camera / video with inference-paced playback and DB-tree capture

SAM 2 / 2.1 / 3 Segmentation (qSAM3)

Promptable segmentation with points, boxes and text prompts (SAM3), plus video object tracking — a native ggml re-implementation of the upstream demo, no Python required.

  • 39 published GGUF models (SAM3 / SAM2.1 / SAM2 backbones)
  • Export masks as annotated images into the DB tree

TRELLIS.2 Image-to-3D (qTrellis)

Turn a single photo into a 3D triangle mesh with per-vertex PBR materials — DINOv3 encoding, flow-matching DiTs and FlexiDualGrid decoding, fully in-process on ggml.

  • Presets from 64³ coarse preview to the 1024³ Full cascade
  • GLB export with UV-atlas texturing (xatlas + meshoptimizer)

RF-DETR Detection & Segmentation (qRFDetr)

Real-time object detection (COCO 91-class layout) with optional instance masks, per-class allowlist filtering, and inference-paced live camera / video playback.

  • 44 GGUF variants (11 model sizes × 4 quantizations)
  • GPU latency from 13 ms per image (nano f16)

Background Removal (qRMBG)

RMBG-2.0 (BiRefNet-Swin-L) GGUF for high-quality transparent background removal, with a raw alpha-matte API for downstream compositing workflows.

  • Image and live-video tabs over a checkerboard preview
  • Custom CUDA kernels and Vulkan shaders

DeepLSD Line Extraction (qDeepLSD)

Wireframe line-segment extraction from GGUF distance + angle fields with AFM-guided LSD post-processing — feed registration and matching pipelines directly.

  • Wireframe (indoor) / MegaDepth (outdoor) variants
  • Export detected segments as ccPolyline entities

OCR Text, Layout & Tables (qOCR)

PP-OCRv4 GGUF text detection and recognition with English / Japanese / Chinese+English recipes, plus opt-in SLANet_plus layout analysis and table structure recognition — results overlaid PP-Structure style.

  • EN / JA / CH+EN recognition recipes
  • Opt-in layout + table stages with DB-tree overlay

Open-World Keypoint Detection (qGKD)

GKDT-L (ECCV 2026) GGUF detects semantically meaningful keypoints from text, visual 1-shot, multimodal or multi-object prompts — no fixed category set, no Python at runtime.

  • Four prompt modes: text / visual 1-shot / multimodal / multi-object
  • Multi-object mode reuses qYOLO World boxes, then GKD per box

Image Tagging & Captioning (qRAM)

Recognize Anything / RAM++ / Tag2Text GGUF for open-set image tagging and captioning over batches, DB images and camera/video streams.

  • All logits and thresholds exposed for tuning
  • JSON / CSV / text export of tags and captions

Scene Relation Graphs (qRelateAnything)

RelSGG ViT / ConvNeXt GGUF (24 models) builds subject–predicate–object relation graphs over detected objects, with Kalman-tracked smoothing for video.

  • Interchangeable detector: YOLOE / YOLO-World / RF-DETR
  • Relation edges on images and tracked video objects

Open-Vocab Grounding & Region QA (qVLXSeek)

VLX-Seek 1.5-10B GGUF retrieves candidate regions instead of generating coordinates — detection, counting, reasoning detection, VQA, region captions and region OCR stay stable and reject absent targets explicitly.

  • Seven upstream tasks with EN / ZH prompt templates
  • Region OCR reads text at target indexes via PP-OCR proposals

Unified Visual Perception (qWeVisOne)

WeVisOne-VL 2B/4B (Qwen3-VL) GGUF answers with structured box tokens — eleven tasks from detection and counting to OCR, segmentation and matting, with a pixel decoder for per-object alpha mattes and explicit None rejection.

  • Eleven upstream tasks on one model, 2B / 4B families
  • Pixel decoder alpha mattes; headless -WEVISONE_RUN batch

InstantMesh Image-to-3D (qInstantMesh)

Single photo to a textured 3D mesh: Zero123++ 6-view diffusion, FlexiCubes mesh extraction and UV atlas — 14 GGUF files, fully in-process on ggml.

  • Zero123++ multi-view diffusion → FlexiCubes mesh
  • xatlas UV atlas with GLB / OBJ export

SAM 3D Objects Image-to-3D (qSAM3D)

SAM 3D Objects GGUF reconstructs a 3D object from one photo — a Gaussian splat PLY plus an optional FlexiCubes mesh, with optional RMBG matting for the object mask.

  • Gaussian splat PLY + optional FlexiCubes mesh
  • Shared RMBG model for automatic object-mask matting

QuerySplat Unposed Photos to 3DGS (qQuerySplat)

QuerySplat + VGGT-Omega GGUF predicts a full 3D Gaussian Splatting scene from 2–16 unposed photos — 524 288 gaussians feed-forward, with a built-in CPU rasterizer rendering the predicted views.

  • Optional test-time optimization (TTO) against the input pixels
  • Point cloud, camera sensors, depth and renders into the DB tree

MapAnything Metric Reconstruction (qMapAnything)

Universal feed-forward metric multi-view reconstruction across six model families — VGGT-Omega / MapAnything / Pi3 / Pi3X / VGGT-1B / DUSt3R GGUF, routed by the GGUF architecture key.

  • ETH3D benchmark anchoring with Sim3 alignment
  • Pointmaps, depth and camera poses from images alone

LingBot-Map Streaming RGB-D (qLingbotMap)

LingBot-Map GCT GGUF streams ordered image folders or video into a live 3D map — per-frame updates, camera frustums and native sky masking, fully in-process.

  • Live per-frame map + camera frustums in the DB tree
  • Native sky masking; video input via OpenCV

OpenPCDet LiDAR 3D Detection (qOpenPCDet)

OpenPCDet GGUF (54 models) runs PointPillars / SECOND / PV-RCNN style detectors on KITTI and nuScenes point clouds — native ggml inference, no Python runtime.

  • 18 KITTI / nuScenes checkpoints × 3 quantizations
  • Per-class wireframe boxes + CSV export

AnyLabeling Annotation Workbench (qAnyLabeling)

X-AnyLabeling-style workbench for image and 3D annotation — shapes, brush, magic wand, video tracking and 3D cuboids, with every AI assist running locally through the shared AICore catalogs.

  • YOLO / SAM3 / RF-DETR assists from the AICore catalogs
  • Fully local annotation — no cloud service required

Enable with -DAICore_ENABLED=ON plus individual PLUGIN_STANDARD_Q* flags. See the build guide for Vulkan/Metal/CUDA options.

Download ACloudViewer

All current and past release downloads are available on GitHub releases.

Prefer a one-line install? The cross-platform npm bootstrap downloads and runs the matching installer for your OS automatically. Pick a channel: stable — npm install -g @asher-1/acloudviewer (latest official release); preview — npm install -g @asher-1/acloudviewer@next (newest development build); or an exact version — @asher-1/acloudviewer@@VERSION@. Then run acloudviewer install.

Select options above to see available downloads

Python Installation

1

Download Wheel File

Download the .whl file for your system and Python version from GitHub Releases

💡 Due to file size exceeding PyPI limits, manual download is required

2

Install Wheel File

pip install cloudviewer-*.whl

Example: pip install cloudviewer-@VERSION@-cp310-cp310-win_amd64.whl

Supports Python 3.10-3.12 | Ubuntu 20.04+, macOS 10.15+, Windows 10+ (64-bit)

Quick Start

Python Quick Start

1

Download & Install

Download the corresponding .whl file from GitHub Releases, then install:

pip install cloudviewer-*.whl

💡 Due to large file size, direct PyPI installation is not supported

2

Verify Installation

python -c "import cloudViewer as cv3d; print(cv3d.__version__)"
3

Run Example

import cloudViewer as cv3d # Create sphere mesh mesh = cv3d.geometry.ccMesh.create_sphere() mesh.compute_vertex_normals() # Visualize cv3d.visualization.draw(mesh, raw_mode=True)

C++ Quick Start

1

Clone Repository

git clone --recursive https://github.com/Asher-1/ACloudViewer.git
2

Build Project

cd ACloudViewer mkdir build && cd build cmake .. make -j$(nproc)
3

Run Example

./bin/ACloudViewer

For detailed compilation instructions, please refer to BUILD.md
